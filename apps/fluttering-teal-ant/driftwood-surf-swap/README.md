# driftwood-surf-swap

A single-page static marketplace for used surfboards. The prompt is explicit: no backend, no build step, one self-contained index.html with inline CSS/JS. Since there's no server-side logic or persistent data requirement beyond a hardcoded/seeded listing set baked into the page, a static_site is the only primitive that genuinely serves this — a web_service or postgres would add infrastructure the prompt directly asks not to have. Listings are treated as static seed content rendered client-side (e.g., from an inline JS array), with client-side filtering/search over that in-memory data.

Generated by the Airo factory from the prompt: "let's make a marketplace for used surf boards Build this as a simple single-page static site: - One self-contained index"

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/jacobprall/airo-apps with the Blueprint Path set to:

```text
apps/fluttering-teal-ant/driftwood-surf-swap/render.yaml
```

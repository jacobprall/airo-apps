# happy-paws

A marketing landing page for Happy Paws, a neighborhood dog walking business. The goal is to convert visitors into booked walks/meet-and-greets, so the site is content-driven: services, pricing, service area, walker bios, testimonials, and a clear call-to-action. No user accounts, bookings storage, or dynamic data are needed for a launch landing page, so a single static site is the smallest primitive that fully serves the prompt — no web_service, postgres, or key_value is justified since nothing needs to run server-side logic or persist data beyond the page content itself.

Generated by the Airo factory from the prompt: "Build a landing page for a dog walking business called Happy Paws"

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/jacobprall/airo-apps with the Blueprint Path set to:

```text
apps/demo/happy-paws/render.yaml
```

# happy-paws-dog-walking

A single static marketing landing page for Happy Paws, a neighborhood dog walking business. The site needs no per-request logic or persisted data — services, pricing, and testimonials are fixed marketing copy — so a static_site is the only primitive required. It's served fast off Render's CDN and can be updated by editing content in the repo, with a mailto/tel call-to-action replacing the need for a backend contact-form service.

Generated by the Airo factory from the prompt: "Build a landing page for a dog walking business called Happy Paws"

## Infrastructure

- static_site

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/jacobprall/airo-apps with the Blueprint Path set to:

```text
apps/demo/happy-paws-dog-walking/render.yaml
```

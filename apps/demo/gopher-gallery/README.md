# gopher-gallery

A whimsical brochure-style storefront selling pet gophers as quirky companion critters. Since the prompt explicitly calls for a static site and there's no need for logins, live inventory, or order processing beyond a simple contact/adopt CTA, the entire experience is served as pre-rendered HTML/CSS/JS with no backend or database — a static_site is the only primitive required.

Generated by the Airo factory from the prompt: "a static site for selling gophers"

## Infrastructure

- static_site

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/jacobprall/airo-apps with the Blueprint Path set to:

```text
apps/demo/gopher-gallery/render.yaml
```

# el-fuego-tacos

A single-page brochure site for El Fuego Taco Stand, a street-food taco cart. The prompt explicitly asks for a static, backend-free, single self-contained index.html, so the only primitive needed is a static_site — there's no data that must persist between requests (menu, hours, and location are fixed content baked into the page) and nothing needs server-side computation, so a web_service, postgres, or key_value store would be unjustified overhead.

Generated by the Airo factory from the prompt: "let's make a site for a taco stand Build this as a simple single-page static site: - One self-contained index.html with "

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/jacobprall/airo-apps with the Blueprint Path set to:

```text
apps/official-emerald-primate/el-fuego-tacos/render.yaml
```

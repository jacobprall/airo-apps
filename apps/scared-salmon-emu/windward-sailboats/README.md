# windward-sailboats

A single-page static storefront for a boutique sailboat dealer. The prompt explicitly calls for a simple, self-contained static site with no backend, server, or build step, so a lone static_site primitive is the right (and only) fit — there's no per-request logic or persistent mutable data that would justify a web_service, postgres, or key_value store. All boat listings are baked into the inlined HTML/CSS/JS as static content.

Generated by the Airo factory from the prompt: "write a website to sell sailboats Build this as a simple single-page static site: - One self-contained index.html with a"

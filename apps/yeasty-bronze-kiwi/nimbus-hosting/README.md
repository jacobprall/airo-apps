# nimbus-hosting

A single-page marketing site advertising "Nimbus Hosting," a fictional web hosting company. Since the prompt explicitly calls for a static, backend-free, single-file site with no data persistence or server-side logic, the only primitive needed is a static_site. There's no per-request computation, no user accounts, and no data that outlives a request, so a web_service, postgres, or key_value store would be unjustified overhead.

Generated by the Airo factory from the prompt: "let's make a site advertising web hosting Build this as a simple single-page static site: - One self-contained index.htm"

## Infrastructure

- static_site

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/jacobprall/airo-apps with the Blueprint Path set to:

```text
apps/yeasty-bronze-kiwi/nimbus-hosting/render.yaml
```

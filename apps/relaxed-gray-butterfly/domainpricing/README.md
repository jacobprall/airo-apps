# domainpricing

A single static marketing page advertising domain name registration pricing — TLD price cards, a comparison table, and FAQ. No dynamic data, no per-request logic, and nothing that needs to persist beyond the page itself, so a single static_site is the entire, correctly-sized footprint. No web_service, database, or cache is justified since there is no backend logic, no user data, and no state to store.

Generated by the Airo factory from the prompt: "let's make a site advertising domain pricing Build this as a simple single-page static site: - One self-contained index."

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/jacobprall/airo-apps with the Blueprint Path set to:

```text
apps/relaxed-gray-butterfly/domainpricing/render.yaml
```
